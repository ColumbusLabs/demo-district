# Blender asset pipeline

World assets that benefit from real modelling are generated by scripts here with Blender's
Python module (`bpy`), then compressed for the web. The scripts are the source of truth: the
GLB in `public/world/` is a build output, committed so the site needs no build-time Blender.
Nothing here runs in CI or the app bundle.

| Script | Output | What it makes |
| --- | --- | --- |
| `trees.py` | `public/world/models/trees.glb` | Three upright street trees and the leaning framing tree, each at two levels of detail, with a generated leaf-spray atlas and bark texture. |

## Setup

- Python 3.11 with `pip install -r tools/blender/requirements.txt` (the `bpy` wheel, ~350 MB). Blender 5.0 itself also works: `blender -b -P tools/blender/trees.py -- --out …`.
- Node, for the compression step (`npx @gltf-transform/cli`, fetched on demand at a pinned version; not a project dependency).

## Rebuild

```sh
tools/blender/build-trees.sh                      # regenerate public/world/models/trees.glb
tools/blender/build-trees.sh --preview docs/art   # also write docs/art/trees-blender.jpg (Cycles, ~1 min on 4 CPUs)
```

`trees.py` prints triangle and vertex counts per mesh; the intermediate uncompressed GLB and
textures go to `tools/blender/build/` (ignored).

## Contract with the world code

`src/world/district/landscape.ts` loads the GLB and expects:

- Nodes `street_a|street_b|street_c|framing` + `_lod0|_lod1`, each a mesh with two primitives whose materials are named `tree_bark` and `tree_leaves`.
- Meters, +Y up, trunk base at the origin; the framing tree leans toward +X.
- `COLOR_0` on both primitives. Bark carries a tint; leaves carry baked crown occlusion and color jitter. No lighting is baked, so the golden-hour sun and sky light the trees in the scene.
- Leaf normals point out of the crown (soft volume shading); leaves are alpha-masked at 0.5 and double-sided.
- Meshopt-compressed, quantized geometry and WebP textures. The loader bakes node transforms into float geometry, so quantization is transparent.

The world code replaces the file's materials with its own (vertex colors, alpha test, wind
sway), so material tweaks here only affect the Cycles preview and other glTF viewers. If the
file fails to load, the district falls back to its procedural trees.

## Budgets

LOD0 is used for the 28 trees in planters and on the terrace (≈1.5k triangles, 2k for the
framing tree); LOD1 for up to 100 grove and street trees (≈430 triangles). Keep spawn under
the 150k-triangle and 120-draw budgets in `docs/PERFORMANCE_BUDGET.md`, and re-measure with
`node scripts/measure.mjs` after any change to counts.

## Adding assets

Generate everything from code or CC0 sources, record the output in `public/world/LICENSES.md`,
and keep the file local under `public/world/`.
